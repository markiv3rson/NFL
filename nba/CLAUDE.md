## How models are tested

Train on earlier games only (weekly walk-forward: every game is predicted using only games before its week). Tuned on 2009-2016 only; 2017-2026 is the untouched test. A pattern is kept only if it beats break-even (52.38% at -110) in EVERY period (2008-13 / 2014-19 / 2020-now) with 60+ games in each. PICK = 56%+ over all games, LEAN = between break-even and 56%. Moneyline patterns must beat the market's own win chance by 3+ points in every period.
Every scan also runs on shuffled outcomes to count how many "winners" pure luck produces.
